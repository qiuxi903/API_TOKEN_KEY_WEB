使用说明

GUIDE
1
设置前缀并生成

输入自定义前缀（如 siteA/），点击「生成重定向」，所有模型会自动添加前缀。

2
复制「渠道模型」→ 粘贴到「自定义模型名称」→ 点击「填入」

将真实模型名（逗号分隔）粘贴到 NewAPI 渠道的「自定义模型名称」输入框，点击「填入」。这些是上游 API 能识别的官方名称。

3
复制「重定向 JSON」→ 粘贴到渠道的「模型重定向」

将 JSON 粘贴到 NewAPI 渠道的模型重定向字段。用户请求 siteA/gpt-4o 时会自动映射为 gpt-4o 发给上游。
